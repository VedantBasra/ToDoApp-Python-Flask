# 📝 Flask To-Do App

A simple and clean to-do list web application built using **Python (Flask)** and **HTML**, styled with **Semantic UI**.

---

## ✨ Features

- ✅ Add and delete tasks instantly
- 💡 Lightweight and beginner-friendly Flask setup
- 🎨 Responsive UI with Semantic UI
- 🌐 Runs locally in your browser (no external DB needed)

---

## 🔧 Setup Instructions

1. **Clone the repository**:
   ```bash
   git clone https://github.com/VedantBasra/ToDoApp-Python-Flask

2. Navigate into the project directory:
   
   ```bash
   cd your-repo

3. Run the application:
   
   ```bash
   python app.py

4. Open your browser and go to http://localhost:5000/ to see the app.
